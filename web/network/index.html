READ THE NETWORK

Connections with evidence.
Uncertainty made visible.

Accounts are points. Payments are paths.

Arrowheads show direction; thicker paths carry greater total value. The account selector and time window reduce clutter. Multiple payments between the same endpoints share a path. Each small point on a path represents a recorded payment. Select a point or transaction ID to inspect it. Its position along the path is for spacing, not time or geography. Playback advances the clock by seconds, minutes or hours. Press “Next payment” to skip quiet periods.

Unknown means unknown.

Bank accounts use AC identifiers; external beneficiaries use EX identifiers. Unidentified sources and recipients remain grouped placeholders. This dataset does not establish a bank-wide ownership graph or locate criminals.

Four rules, traceable evidence.

Every completed alert reconciles to the existing PostgreSQL AML rules. During replay, each alert version contains only evidence available at the displayed UTC time. Supporting transactions are distinguished from the transactions included in the alert amount. Repeated use of evidence across flags means alert values must not be added as unique suspicious volume.

The proposed bank-facing value is traceable review: payment → rule → evidence → analyst decision. This is a product hypothesis to validate with institutions, not a claim of unique market capability. Research prototype, synthetic data only. No bank connectivity, payment blocking, shared case management or production detection claim. The full local analytics interface and setup are available in the repository.
