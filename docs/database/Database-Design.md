# Overview

The NorthStar Bank Operational Database is designed to support customer onboarding, account management, transaction processing, compliance monitoring, and analytics.

The database follows a normalized relational model and serves as the primary operational data source for the PySpark ETL pipeline, Snowflake Data Warehouse, machine learning models, and business intelligence dashboards.

Version 1.0 defines the complete database architecture and business domains. Individual table structures are documented separately in the Data Dictionary.

---

# Database Domains

The database is organized into six logical domains.

## 1. Customer Management

Responsible for storing customer identity, contact information, and onboarding details.

| Table | Description |
|--------|-------------|
| `customers` | Stores core customer information. |
| `customer_addresses` | Stores customer address history. |
| `customer_contacts` | Stores customer phone numbers and email addresses. |
| `customer_documents` | Stores identity documents such as passports and national IDs. |

---

## 2. Banking

Responsible for daily banking operations and financial transactions.

| Table | Description |
|--------|-------------|
| `accounts` | Stores customer bank accounts. |
| `transactions` | Stores all financial transactions. |
| `beneficiaries` | Stores registered payment beneficiaries. |
| `cards` | Stores debit and credit card information. |

---

## 3. Compliance

Responsible for AML, KYC, sanctions screening, and investigation workflows.

| Table | Description |
|--------|-------------|
| `kyc_reviews` | Stores customer KYC verification records. |
| `aml_alerts` | Stores alerts generated by AML monitoring rules. |
| `investigation_cases` | Stores compliance investigation cases. |
| `case_notes` | Stores analyst investigation notes. |

---

## 4. Reference Data

Stores master data shared across multiple systems.

| Table | Description |
|--------|-------------|
| `countries` | Stores supported countries. |
| `currencies` | Stores supported currencies. |
| `branches` | Stores bank branch information. |
| `transaction_types` | Stores transaction categories (Deposit, Withdrawal, Transfer, etc.). |
| `merchant_categories` | Stores merchant category codes (MCC). |

---

## 5. External Compliance Data

Stores regulatory and compliance reference datasets.

| Table | Description |
|--------|-------------|
| `sanctions_list` | Stores sanctioned individuals and organizations. |
| `pep_list` | Stores Politically Exposed Persons (PEP). |
| `country_risk` | Stores country risk ratings used in AML monitoring. |

---

## 6. Analytics

Stores outputs generated by analytical models.

| Table | Description |
|--------|-------------|
| `customer_risk_scores` | Stores calculated customer risk scores. |
| `model_predictions` | Stores machine learning prediction results. |
